# Css

## Fire-theme tokens: "lime" = ember accent
TELF's theme is "ember over forest": the brand accent token `lime` is ember-orange #D8501E (NOT green). `forest-dark` = soot #171009 (night base), `forest` = muted moss #2E3D24 (living-forest counterpoint, used for headings on light), `cream` = warm ash #F3EBDF, `sage` = smoke-olive #7D6B4C, `ink` = warm black #20140D for text-on-ember buttons. On the map, administrative boundaries use muted olive #6B7B4E so they stay distinct from ember fire points. Any new public UI should derive colors from these tokens, never reintroduce the old green #C8D84A/#1C3A14 brand.
